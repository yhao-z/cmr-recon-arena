## Protocol for the agent

1. If `STATUS` above is `UNINITIALIZED`: ask the user the six questions listed
   in `SKILL.md → ⚑ First-Run Protocol`, all in one round.
2. Write the answers into the table below. Keep the field names exactly.
3. Set the first line to `STATUS: INITIALIZED <YYYY-MM-DD>`.
4. Build ready-to-copy commands into `## Ready-to-run commands` below, using
   this table's values (`cd <repo_root>`, `<env_activate>`, …).
5. From then on, read this file before running anything — do not re-ask. Only
   re-ask when the file is missing or the user says the setup changed; then
   update it in place and bump the date.
